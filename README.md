# 旅游网站系统 (Travel Website System)

一个现代化的旅游网站前端项目，展示热门旅游目的地和旅游产品信息。

## 项目简介

本项目是一个单页面旅游网站，包含以下功能模块：
- 导航栏和页脚
- 轮播图展示热门景点
- 热门目的地推荐
- 旅游产品卡片展示
- 联系我们表单

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式设计（响应式布局）
- **JavaScript** - 交互功能（轮播、表单验证等）

## 项目结构
new_web_travel_system/ 
├── images/ # 图片资源目录 │ ├── bali.jpg │ ├── tokyo.jpg │ ├── paris.jpg │ └── ... 
├── index.html # 主页面 
├── styles.css # 样式文件 
├── script.js # JavaScript 交互逻辑 
└── README.md # 项目说明文档


## 快速开始

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/linchi124/new_web_travel_system.git

# 进入项目目录
cd new_web_travel_system

# 使用浏览器打开 index.html 文件即可预览
# 推荐使用 Live Server 扩展（VS Code）进行开发预览
```

### 开发建议

1. 使用 VS Code 作为开发工具
2. 安装 Live Server 扩展以便实时预览
3. 确保所有图片资源正确加载

## 功能特点

- ✅ 响应式设计，支持移动端和桌面端
- ✅ 图片轮播展示
- ✅ 热门目的地推荐
- ✅ 旅游产品卡片展示
